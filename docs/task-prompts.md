# TASK実行プロンプトと成果報告書

TASK実行時は、今回のTASK名・指示、完了条件、ツリーの背景と親ノードの指示、直接の依存先TASK名と報告書パス、今回の報告書保存指示を渡します。先行TASKの結果本文やNotionの過去結果本文は埋め込みません。ツリー生成などの計画プロンプトは対象外です。

報告書の保存先は実行先の作業ディレクトリ下の `.taskdesk/reports/<treeId>/<taskId>/<runId>.md` です。AIにディレクトリ作成とMarkdown保存を指示し、実施内容、成果物、検証結果、完了条件ごとの根拠、未解決事項を記載させます。修正後の再判定では元の報告書を更新します。

保存先・ホスト・保存報告状態は実行状態に保持し、後続TASKへ引き継ぎます。最終回答の `TASKDESK_REPORT:` に指定パスが含まれる場合は「AIが保存を報告」と表示します。これはファイルの実在検証ではなく、完了ラベルを決める根拠にも使用しません。

旧TASKの結果に `docs/` または `reports/` 配下のMarkdownパスがあれば、未検証の候補として引き継ぎます。パス未登録・保存未確認・別マシンの資料はプロンプトに明記します。別マシンへファイルを自動転送せず、参照できない根拠を推測しないようAIへ指示します。

# Codex の終了通知と自動完了

TaskDesk が起動した Codex の `notify` を回収し、応答終了を表示します。回答に特別な文字列を書く必要はありません。Orca の既存通知は引き継ぎ、ユーザーの恒久的な Codex 設定は変更しません。Claude Code は手動記録です。

## 設定

1. 作成画面またはツリーの実行設定で、Orca のプロジェクト・ホスト・ワークツリーを指定します。
2. 「Codex の終了通知」を「終了通知を回収する」にします。ローカルは直接回収します。
3. SSH ホストでは「設定 → マシンと AI ツール」で同じホスト・OS ユーザーへの SSH 接続を登録し、「通知回収に使う SSH 接続」で対応付けます。TaskDesk を WSL で動かしている場合は WSL からの鍵認証・known_hosts・Node.js 実行パスを設定してください。Orca のホスト名だけでは SSH 接続を推測しません。
4. TASK を開き「完了条件の自動検証」で実行ファイル・引数の JSON 配列・制限時間を入力します。
5. その検証が TASK の全完了条件を確認する場合だけ、「成功時は自動完了する」を有効にして保存します。

例えば専用の検証スクリプトがあるなら、プログラムを `node`、引数を `["scripts/verify-task.cjs"]` とします。プログラムは実行先の同じワークツリーを作業ディレクトリとして起動します。シェルは使わず、`&&` やリダイレクトを引数から解釈しません。Windows の `.cmd` ではなく実行ファイルや Node.js スクリプトを指定してください。検証には実行先ユーザーの権限が使われるため、自分で確認した検証プログラムを指定します。

## 結果

- 終了通知を受信しても、検証未設定なら「確認待ち」です。「結果を記録」には Codex の回答が入力されます。
- 検証プログラムが終了コード 0 なら「完了」、非 0 なら「想定外結果」です。
- プログラムの起動失敗・タイムアウトは「エラー」です。完了以外では後続 TASK を開始しません。
- 承認必須の TASK は、自動検証後も人による承認が必要です。
- 検証前後に Codex のターンが変わった場合、結果を確定せず確認待ちにします。
- 計画生成は応答 JSON の構造を検証して取り込みます。回収未設定などの手動モードでは「計画 JSON を記録」を使えます。

## 接続・保存

通知は実行先ユーザーの `~/.taskdesk/notifications/<attemptId>/` に保存します。モデルに書かせるファイルではなく、Codex が起動する通知プログラムが保存します。既存の `notify` は Codex の `config/read` で取得し、元の JSON を転送します。

実行時には回収側で準備したディレクトリを Orca の起動プログラムが照合し、ホスト名・ユーザー・作業ディレクトリ・実行専用識別子の一致と通知経路の往復を確認してから Codex を開始します。異なる SSH 接続を誤って指定した場合はプロンプトを送信しません。

イベントは受領後も保存し、TaskDesk の実行履歴側にも受領 ID・元イベント・判定結果を保存します。重複通知や再接続で同じ検証を二重起動しません。Web サーバー再起動中も既存ワーカーは継続します。停止・タイムアウトでは専用タブと当該実行の検証だけを停止します。切断中は停止確認を保証できないので、実行先で状態を確認してください。

## 対応確認と制限

2026-09-20、Codex 0.155.1 / Orca 1.4.205 で Windows ネイティブ、および WSL から Windows 版 Orca を操作する経路の実通知・検証・自動完了を確認しました。既存の通知先との共存も確認しました。g15 は接続エラーのため SSH 先の実機試験は未実施です。

`notify` はターン終了だけを通知するため、検証前後のターン照合には該当 thread-id の Codex 保存イベントを補助的に読み取ります。任意の「最新セッション」は使いません。`session_meta` の CLI / user セッション、`task_started` / `task_complete` の turn-id を照合し、子セッションは除外します。この保存形式は内部形式のため、形式変更・記録なし・曖昧な識別・32 MB 超のセッション記録では自動確定を行わず確認待ちになります。

通知非対応・設定読み取り失敗は、通知経路を設定できたと仮定して実行しません。「手動で結果を記録する」を選択して利用できます。SSH 回収接続が未設定の場合も、画面に手動記録モードと表示します。

更新前から動いている TASK に通知設定は後付けしません。旧 TASK は手動記録し、新しい実行から適用します。
